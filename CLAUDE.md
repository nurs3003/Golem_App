## What This Is

A fully-built Golem R Shiny application (`GolemAppProject`) for FIN 451 — Risk and Trading Management. It explores energy futures market dynamics across six markets (CL, BRN, NG, HO, RB, HTT) and the US Treasury yield curve, deployed via Docker to GitHub Container Registry.

## Development Commands

```r
devtools::load_all()          # reload all R/ functions
GolemAppProject::run_app()    # run the app locally
golem::run_dev()              # alternative dev runner with auto-reload
devtools::document()          # regenerate NAMESPACE and Rd files
devtools::check()             # full R CMD check
```

## Architecture

**Small-r reactive pattern**: one `reactiveValues` object (`r`) created in `app_server.R` and passed by reference to every module. Only `mod_market_selector_server` writes to `r`. All other modules read from it.

```
r <- reactiveValues(data, cmt_data, selected_markets, date_range)
```

**Data loading**: `fct_load_data.R` reads two Apache Arrow feather files at startup:
- `inst/extdata/futures_data.feather` — parsed from `RTL::dflong`, columns: date, market, contract (int), value
- `inst/extdata/cmt_data.feather` — FRED CMT yields, columns: date, maturity_years, value

These files are regenerated by `.github/workflows/data-refresh.yml` every weekday at 18:00 UTC.

**Shared config** (`app_config.R`):
- `market_colors` — named colour vector, one per ticker
- `alert_color` — reference line colour distinct from market colours
- `event_vlines(date_range)` — returns plotly `shapes` + `annotations` for Lehman Bros (2008-09-15), COVID-19 (2020-03-16), Russia-Ukraine (2022-02-24); used in vol and factor charts
- `%||%` — null-coalescing operator

## Modules

| File | Tab | Key outputs |
|---|---|---|
| `mod_market_selector.R` | Selector bar (all tabs) | Writes `r$selected_markets`, `r$date_range` |
| `mod_market_overview.R` | Overview | KPI value boxes, Morning Briefing DT, market profile cards |
| `mod_storage.R` | Fundamentals | Storage/fundamental charts |
| `mod_forward_curve.R` | Curves | Commodity curves, yield curve, roll yield, macro context |
| `mod_volatility.R` | Volatility | Rolling vol, vol surface, vol cone, VaR |
| `mod_codynamics.R` | Correlations | Correlation matrix, rolling correlation, PCA factor analysis |
| `mod_seasonality.R` | Seasonality | Monthly avg returns, box plots, year-over-year |
| `mod_spreads.R` | Spreads | Calendar and inter-market spreads (own date range input) |
| `mod_hedge_ratios.R` | Hedging | Cross-market and term-structure rolling OLS beta |

## Key Conventions

- All rolling calculations use `slider::slide_dbl` / `slider::slide2_dbl`
- Log returns (`diff(log(value))`) throughout — never price levels — to avoid spurious regression and ensure stationarity
- `%||%` is used for colour fallbacks: `market_colors[mkt] %||% "#888888"`
- The selector bar is hidden on Overview, Fundamentals, and Spreads tabs via `shinyjs` in `app_server.R`
- Spreads tab has its own `dateRangeInput` (independent of the global selector)
- Value boxes on Overview use `nav_box()` helper (defined inside `output$value_boxes` renderUI) to wrap clickable divs that navigate to specific tabs and sub-tabs via JS `querySelector`

## CI/CD

- `data-refresh.yml` — weekdays 18:00 UTC, regenerates feather files, commits back
- `docker-publish.yml` — on push to main, builds multi-platform image (amd64 + arm64), pushes to `ghcr.io/nurs3003/golem_app:latest`
